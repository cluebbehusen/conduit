# Conduit

A simple SSH client for iOS, leveraging [Citadel](https://github.com/orlandos-nl/Citadel) and [SwiftTerm](https://github.com/migueldeicaza/SwiftTerm).

## Features

- **Saved Hosts**: Save hosts to device
- **Password & SSH Key Authentication**: Supports password login and Ed25519/RSA key authentication
- **Secure Credential Storage**: Passwords and keys stored in iOS Keychain with optional Face ID/Touch ID protection
- **Known Hosts Verification**: SSH host key fingerprint verification with persistent trust storage
- **Native iOS Design**: Built with SwiftUI and Apple's Liquid Glass design language
- **Quick Keys**: Visual display of modifier keys not easily accessible from software keyboard
- **Personalization Settings**: Allows customizing theme and quick key visibility
